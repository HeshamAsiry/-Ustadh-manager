# Ustadh Manager

A mobile-first teaching management app for Arabic, Quran and Islamic studies teachers.

## Product scope
- Student profiles and flexible learning paths
- Multi-subject lessons
- Time-zone aware scheduling
- Conflict prevention and availability
- Manual makeup lesson scheduling
- Personal schedule for memorization, revision, study and preparation
- Lesson reports with private notes and parent-ready copy
- Arabic, French and English UI/report support
- Quran memorization, revision and exams
- Monthly teaching-hour tracking
- Payments and reporting
- Parent portal reserved for a future phase

## Stack
Next.js + TypeScript + Tailwind CSS + Supabase + Vercel.
